Camera Configuration

Camera support depends on build options and installed SDKs. Typical backends include:

  • FireWire cameras compliant with IIDC/DCAM (IEEE1394). See Damien Douxchamps' camera list.
  • GigE Vision cameras via the Aravis library.
  • Andor Neo/Zyla (CameraLink) with the vendor SDK and a frame grabber.
  • Raptor cameras (Falcon, Ninox640) with the vendor SDK.
  • Allied Vision cameras via VimbaX.
  • Raspberry Pi camera (when enabled).
  • USB cameras (UVC) when enabled.

On startup, connected cameras are added to the Instruments menu. Selecting a camera opens a live view window; frame rate depends on resolution and workstation graphics capability. The camera window exposes common controls such as exposure and gain when supported by the device.

Live view

The video area always receives the full-resolution sensor frame; nothing is downscaled or compressed before display. How the frame is drawn is chosen from the camera window menus:

  • Resolution (480x320, 640x480, 1280x960) sets the size of the video area. In the default fit mode the whole sensor is scaled into that area with its aspect ratio preserved, so black bars may appear on two sides.
  • View > Native 1:1 pixels draws one sensor pixel per screen pixel. The frame is then usually larger than the video area and scroll bars let you pan over the sensor. Untick the entry to return to fit mode.

In both modes you can zoom by dragging a rectangle with the left mouse button. The selection snaps to the aspect ratio of the video area so the zoomed region fills the display; it is magnified without smoothing, so individual sensor pixels stay visible as blocks. Double-click to return to the full frame.

When the camera exposes properties, the Properties dock shows the sensor pixel under the mouse pointer as x = .. y = .. value = ... The coordinates are real sensor coordinates whatever the zoom or display mode, and the value is read from the acquisition buffer (the raw 16-bit count for 16-bit cameras, else the 8-bit value), not from the rendered image.

The Gray / Hot buttons in the Controls dock select the colour table used to render the 8-bit display; min, max and avg report the statistics of the current frame.
